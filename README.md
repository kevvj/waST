# waST

Bot de WhatsApp que transforma imágenes y videos en stickers de manera automática.

Permite enviar archivos multimedia a través de WhatsApp y recibir stickers listos para usar.

## Funcionalidades

- Transformar imágenes en stickers  
- Transformar videos en stickers animados  
- Responde directamente en WhatsApp  
- Compatible con distintos formatos de medios  

## Tecnologías

- Node.js  
- WhatsApp Web API (o biblioteca equivalente)  
- JavaScript
